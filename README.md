# guia-csstiae-2025

Este repositorio contiene los ficheros fuentes para una guía de preparación de las pruebas selectivas del Cuerpo Superior de Sistemas y Tecnologías de la Información de la Administración del Estado (CSSTIAE) del sector público español en la convocatoria de 2025.

Versión web disponible en:
<https://pmgallardo.github.io/guia-csstiae-2025>

## Construcción

### Prerequisitos para construcción

Requisitos en el sistema para construir el código en local:

- Quarto
- Fuentes Source Sans 3

Comando para instalar el paquete de fuentes con `apt` (Linux basado en Debian):

```bash
sudo apt install fonts-adobe-sourcesans3
```

### Comandos para la construcción

Comando para visualizar en local:

```bash
quarto preview
```

Comando para construir los ficheros de salida:

```bash
quarto render
```
