7.18 CTT (Centro de Transferencia de Tecnología)

Nota
  • Referencias
    • Repositorio forja-CTT en GitHub

El Centro de Transferencia de Tecnología (CTT) es un portal web que tiene como objetivo favorecer la reutilización de soluciones tecnológicas a lo largo.

Es gestionado por la AEAD.

Contiene el directorio de soluciones del CTT (DS-CTT)/index{CTT!directorio de soluciones}, que es un catálogo de soluciones tecnológicas reutilizables en las AAPP.

El repositorio forja-CTT de GitHub alberga proyectos de código abierto de las AAPP.

7.18.1 CISE (Centro de Interoperabilidad Semántica)

Nota
  • Referencias
    • CISE en PAe

El Centro de Interoperabilidad Semántica (CISE) sirve para almacenar, publicar y difundir modelos de datos comunes y sectoriales a las AAPP de la AGE, garantizando que las diferentes administraciones públicas y ciudadanos entiendan la información intercambiada de forma automática.
